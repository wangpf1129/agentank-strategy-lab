# Playbooks

Playbooks turn research into matchup plans for the two primary tanks.

Priority:
1. Improve ladder score, tier/division, and public rank.
2. Preserve each tank's identity.
3. Make wins explainable from replay evidence.
4. Publish only after a focused experiment.

## Current Playbooks

- `dual-tank-roadmap.md`: how freeze-main and teleport-main should grow together.
- `skill-matchups.md`: matchup plans by opponent skill.
