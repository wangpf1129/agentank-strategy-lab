# Data

Raw evidence goes here.

Recommended layout:
- `matches/`: downloaded `agent.json` match replays.
- `leaderboards/`: leaderboard snapshots with fetch time.
- `maps/`: map layouts, map ids, star hot spots, mound positions, and anchor candidates.

Keep raw data immutable when possible. If derived data is needed, write it as a new file instead of overwriting the source replay.
