# Reports

Write summarized experiment results here.

Current top-level metric: ladder score movement (`rankScore`, tier/division/points, public rank). Win/loss and ELO from older reports are historical diagnostics unless a report explicitly says otherwise.

Recommended report names:
- `YYYY-MM-DD-baseline.md`
- `YYYY-MM-DD-ladder-score.md`
- `YYYY-MM-DD-overload-counter.md`
- `YYYY-MM-DD-map-control.md`
- `YYYY-MM-DD-freeze-timing.md`

Each report should link to experiment notes, match ids, and candidate source files.
